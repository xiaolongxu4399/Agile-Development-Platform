# 私聊与云文档（v5 增量）功能与迁移说明

准备日期：2026-10-21。基于 `terry/workplace`（v4，`e62a935`）开发，分支 `feature/dm-and-cloud-docs`。本文描述两块新增能力、数据库迁移步骤与浏览器验收清单；未推送、未部署。

## 功能一：私聊（飞书式一对一消息）

- **入口**：左侧图标栏新增「私信」（未读角标）；团队管理页成员卡片新增「私信」按钮；收到私信通知点击直达会话。
- **范围**：仅同团队成员可互发（跨团队可见同一联系人）；同一对用户只有一条会话。
- **交互**：双栏布局——左会话列表（头像在线点、最后消息摘要、未读数），右消息流（日期分隔、气泡左右分列、我方最后一条显示已读/未读回执）。消息 8 秒轮询，会话列表随工作台 20 秒轮询；进入会话自动把对方未读标为已读。
- **与团队聊天对齐的能力**：输入区带工具栏——**发送文件**（≤100MB，存 `uploads/`；接收方渲染为文件卡片可点击下载，中文文件名正常）与**表情**（8 个常用表情面板）；不含置顶公告与 @提及（私聊场景不需要）。发送文件触发「给你发来文件《文件名》」通知。
- **会话管理**：会话项支持**右键菜单**与悬浮「⋯」按钮——「隐藏会话」仅从我的列表移除（对方来新消息或重新发起时自动恢复）；「删除会话」清空双方全部消息与附件并清理关联通知（菜单内二次确认）。列表头部按钮为「添加」（原「发起私聊」）。
- **等比缩放**：工作台按 1280px 设计宽度整体渲染，窗口/缩放变窄时 transform 等比缩小，任何宽度都保持完整桌面布局（新增 `components/ws/ScaleFrame.tsx` + globals.css 覆盖段；不改动任何配色与昼夜主题）。
- **数据**：`dm_conversations`（`user_a_id < user_b_id` 唯一 + CHECK，`hidden_for_a/b` 隐藏标记）、`dm_messages`（`read_at` 为接收方阅读时间，`attachment_id` 指向文件消息）、`dm_attachments`（私聊文件元数据，文件本体存 `uploads/`）。
- **通知**：新消息写入站内通知（`type=dm`，`entityType=dm`，`entityId=会话 id`），前端导航直接切到私信视图并选中该会话，无需请求校验；删除会话时关联通知一并清理。

## 功能二：云文档（飞书式项目文档库）

- **入口**：左侧图标栏新增「云文档」。文档归属项目，项目成员均可读均可编辑；创建/删除写项目日志。
- **编辑器**：Markdown 子集（标题/粗斜体/行内代码/代码块/列表/引用/分隔线/http(s) 链接），左写右览实时预览，可切纯预览；**自动保存**（停止输入 1.2 秒后 PUT），顶栏常显保存状态（已保存 · 时间 / 正在保存 / 失败原因）；关闭页面前有未保存内容时拦截提醒。
- **历史版本**：每次保存前自动快照旧内容，每篇保留最近 20 版（超出删最旧）；版本列表可查看预览、一键恢复；「恢复」前同样快照当前内容，因此恢复本身可撤销。
- **安全**：渲染器先整体 HTML 转义再替换（`lib/markdown.ts`），无原始 HTML 注入面；链接仅允许 http/https。
- **数据**：`docs`（title ≤80 字，content ≤20 万字符）、`doc_versions`。
- **权限**：删除限创建者与团队 admin/owner（列表与详情均返回 `canDelete`）。

## 数据库迁移（幂等，可重复执行）

在 v4 的 11 个迁移脚本之后追加执行：

```bash
npm run db:add-direct-messages   # 建 dm_conversations / dm_messages
npm run db:add-docs              # 建 docs / doc_versions
```

新库（如本地全新环境）顺序：`db:push` 或先跑 v4 全套脚本再跑上面两条；`db:seed` 幂等，会附带写入 2 篇演示文档与 1 条演示私聊。

## 浏览器验收清单（两个测试账号）

| 场景 | 通过标准 |
| --- | --- |
| 发起私聊 | 「添加」只见同团队成员；选人后建会话并发消息成功 |
| 权限边界 | 尝试与非同团队用户发起（如用接口直调）返回 403；不能给自己发起 |
| 未读与角标 | B 给 A 发消息，A 图标栏「私信」出现角标、会话列表有未读数 |
| 已读回执 | A 打开会话后未读清零，B 侧自己最后一条消息变为「已读」 |
| 通知直达 | A 点击「给你发来私信」通知，自动切到私信视图并选中该会话 |
| 隐藏会话 | 右键或「⋯」菜单隐藏后从列表消失、线程关闭；B 再发消息 A 侧自动恢复并计未读；A 重新「添加」该成员也会恢复 |
| 删除会话 | 菜单二次确认后，双方列表同时消失、消息清零、关联通知清理 |
| 私聊文件 | A 发送文件（含中文名）后 B 侧出现文件卡片，点击下载内容与文件名正确；非会话双方下载 403；删除会话后附件不可再下载 |
| 私聊表情 | 表情面板选择后进入输入框，随消息发送并在双方气泡中显示 |
| 任意窗口宽度 | 拖窄窗口至任意宽度，工作台整体等比缩小，顶栏不折行、面板不隐藏、无堆叠；日/夜主题均正常 |
| 文档 CRUD | 新建（选项目+标题）→ 编辑自动保存 → 返回列表看到摘要与更新者 |
| 版本历史 | 连续多次修改后历史版本 ≤20 条；恢复旧版后内容回滚且「恢复」本身在历史中 |
| 删除权限 | 普通成员看不到他人创建文档的删除按钮；创建者/管理员可删，删除写项目日志 |
| 主题 | 日间/夜间主题下私信与文档界面均正常（复用调色板变量） |
| 旧数据 | 原有项目、任务、聊天、文件不受影响；未跑迁移前新接口返回明确错误 |

## 已知边界

- 无 WebSocket：私聊与文档协作均轮询/最后写入胜出；两人同时编辑同一篇文档，后保存者覆盖，先保存方可从历史版本找回内容。
- 私聊不含表情/图片/文件（团队频道已有文件上传，私聊保持轻量）。
- 文档无评论、无@提醒、无分享到会话卡片——列入后续候选。
